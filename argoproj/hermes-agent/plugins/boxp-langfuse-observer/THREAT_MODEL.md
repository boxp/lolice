# boxp-langfuse-observer: 観測契約と保護境界（BOXP-428）

Owner が確定した契約（`Projects/langfuse-observability/request.md` 冒頭、2026-11-06）: **通常の依頼・応答・tool 入出力・委譲本文を可視化**し、**明確な秘密は発生源/保存送信前に除外**し、**無印平文や未知変換の完全検出不能は残差として許容**する。Langfuse は lolice 内 self-host、Owner 限定 Access、短期 retention。

## 1. 保証するもの（レビューの対象）

- K0 is judged where a tool reads or runs something (BOXP-428 TD-12): the path arguments of a tool (`file_path`, `filePath`, `path`, `notebook_path`, `filename`, `file`, `target_file`) and its command arguments (`command`, `cmd`, `script`, `code`, including an argument vector such as `["bash","-lc",script]`). Text that a tool only carries is not a source: Edit/Write content, descriptions and prompts, the body of a heredoc fed to a program that is not an interpreter (`delegate.py run <<EOF`, `cat > file <<EOF`), an option value with spaces (`--note "..."`, `-m "..."`), `echo`/`printf` text and a `grep`/`rg` pattern. Command substitutions inside such text (`echo "$(cat .env)"`, and in the body of an unquoted heredoc `cat <<EOF` with `$(cat .env)` or `` `printenv` ``, which the shell expands; a quoted `<<'EOF'` body is literal) and `-c` scripts of a shell or interpreter, including a one-word script (`bash -lc '...'`, `bash -c 'printenv'`, `sh -lc env`), are still judged, and a heredoc read by an interpreter (`python3 - <<EOF`, `ssh host bash <<EOF`) is judged as code. Only an unquoted, uncommented `<<TAG` is a heredoc operator: `echo '<<EOF'`, `echo "x <<EOF"`, `echo a # <<EOF` and `echo \\<<EOF` start no heredoc, so the lines after them are judged as commands (quote state carries over lines; an operator it misses only makes its body judged as commands). The environment is a source when it is dumped (`env`/`printenv` with nothing to run; `env` with assignments or options before a command runs that command, so `env LANG=C printenv` and `env -u HOME printenv` are dumps and `env LANG=C sort a.txt` is not; `env -S` is withheld, `set`/`export`/`declare` with nothing to set or `-p`/`-x`, `os.environ`, `process.env`, `getenv()`, `/proc/*/environ`, `.items()`/`.keys()` of them, and `.copy()` of them unless the copy is only assigned or passed as an argument such as `env = os.environ.copy()` / `run(cmd, env=os.environ.copy())`; `print(os.environ.copy())` is a dump) or when a variable with a secret name is printed on the same line (`print(os.environ['GITHUB_TOKEN'])`); reading one variable (`os.environ.get('LAYOUT')`, `process.env.HOST`, `token=os.environ['MCP_TOKEN']` passed to a client) is not. `kubectl`/`oc` is a source when `secret`/`secrets` is a word of the same pipeline segment, not when a later `grep -v secret` filters its output. The remote command of `kubectl exec ... -- cmd` / `oc exec ... -- cmd` is judged like a local one, so `kubectl exec pod -- printenv GITHUB_TOKEN`, `-- env LANG=C printenv` and `-- sh -c 'printenv'` are dumps and `kubectl exec pod -- ls /app` is not. A token file without an extension or a directory (`mytoken`, `access_token`) is a source in a reading position: a path argument, an operand of a program that is not a mention program (`ls`, `grep`, `echo`, `git add` ...), `< file` or `NAME=file`. A command text over 256 KiB or with more than 4096 heredoc operators is not parsed and is withheld.
- Lineage evidence from a header, bearer or URL-credential hit (`known_format_in_tool_output`) counts unless its value is a documentation placeholder (BOXP-428 TD-12): the value after `Bearer`/the header name (and its scheme) or the URL password is empty, starts with `$`, `<`, `{`, `%`, `*` or `[`, is an upper-case name without digits (`YOUR_API_TOKEN`), a lower-case word of at most 12 letters (`bearer token.`), surrounding punctuation ignored, or is `xxx`, `...`, `password`, `pass`, `pwd`, `secret`, `key`, `token`, `api_key`, `access_token`, `changeme`, `your...`, `my...pass...`, `example...`. A placeholder is still masked in place.

## 2. 保証しないもの（Owner 承認済みの残差。レビューで P0 にしない）

TD-12 の残差: 変数経由の読み取り、空白を含む引用されたパスをオプション値として渡す場合、秘密名の環境変数を別の変数や別行を通して出力する場合など、任意のシェル表記は検出できない。上記のプレースホルダ形(数字を含まない大文字だけの値など)の資格情報はその場でマスクされるが、後続本文の保留根拠にはならない。

- 秘密語も既知形式も無い**無印の平文値**（例: 通常名ファイルの中身、`cat /etc/app/config.yaml` の値）と、モデルがそれを**裸で再掲**したもの。
- 既知形式に当たった値の言い換え、部分的な再掲、未知の変換（base64/rot13/gzip 等）、無関係な別 session での再掲。短い名前付き値が prompt や返信に現れた場合の後の再掲。
- 同じ機密コマンド/ファイルの**恣意的なシェル表記**（引用の分割、エスケープ、グロブ、変数経由、未知の別名 CLI）で K0 表を外れるもの。
- Owner の依頼文や system prompt に形式も秘密語も無く書かれた値。
- 秘密語を含む行とその前後行は内容に関係なく伏せるため、無害な語も消える（過剰マスク）。token を含む語が閉じない引用符のあるコマンドにある場合や、`bash -c` の 3 段超の入れ子、4096 文字超のコマンドは解析せず機密源扱い（fail-closed の過剰保留）。tool 名だけ・単語の言及だけ・未観測履歴だけでは**保留しない**。

補助の守り: self-host、Owner 限定 Access、14 日 retention、MinIO 1 日、spool 無し。

## 3. 陽性可視性（空にすれば秘密ゼロ、という退行を不合格にする）

unit `test_a_harmless_turn_is_not_all_withheld` `test_reply_after_an_ordinary_tool_is_sent` `test_reply_after_a_child_used_a_tool_is_sent` `test_tool_bodies_are_sent_through_the_mask`、Chainsaw `fire_harmless_tool` `fire_harmless_lineage`（terminal/read_file/未知 tool の後の応答・次ターン・委譲子・親の要約が sink に原文で届き、`body_policy=sent` が 10 件以上）。各観測の `metadata.body_policy` と trace の `coverage.withheld_reason` で producer 別・理由別の比率を Langfuse 上で読める。

名前付き値の完全一致は session の系譜全体で JSON・percent・HTML エスケープを含めてマスクする（1〜3 文字の値は単語単位）。長すぎる、または数が多すぎて pin できない値が tool 結果にある場合は系譜を保留する。base64 や逆順などの変換、部分的な再掲、1〜3 文字の値が長い語の一部として現れる場合、4 文字以上の記号だけのパスワードが他の記号に隣接して再掲される場合、無関係な別 session、prompt や返信に含まれる短い値の再掲は保証対象外。
