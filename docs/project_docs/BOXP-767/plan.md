# BOXP-767: コハコの家の読み上げを CPU 設定と文の区切りで速くする

Owner 承認: BOXP-761 選択1（reply_id=df56820a-9c69-491b-831d-9fe46b3d878b）。声（コハク／ノーマル）・Gemma・GPU・資源上限・権限・課金は変えない。

## 手順
1. 変更前の実経路を計測（家の配備版画面＋本番 TTS、返答本文を固定。返答到着→最初の音、文間の無音）。
2. lolice: TTS の起動スクリプトで ONNX Runtime の intra-op スレッド数を CPU 枠（8）に合わせ、スピン待ちを止める（本 PR）。CPU 上限 8・メモリ 6Gi は据え置き。
3. 配備後に同じ条件で再計測し、BFF の `tts_synthesized` と CPU throttling も比べる。効果が無ければ戻す（6 スレッドも候補）。
4. その結果をもとに boxp/arch の家の区切り（2 番目以降の最低 60 字）を調整する別 PR。長文・停止・順序・音質の退行を確認。

## 仕様・Lean について
手順2は設定変更のみ（状態や順序の規則を持たない）ので Lean・仕様先行は適用外。手順4の区切り規則は家の現行仕様ノートに例つきで書いてから実装する。
